FOCUS BOARD
===========
A daily challenge tracker for your Windows desktop: day count, progress bar,
a new motivational message every day and a live streak timer - right on your wallpaper.

WHAT YOU NEED
- A Windows 10 or Windows 11 PC. That's it - nothing else to download or install.
  (It uses PowerShell and .NET, which come built into Windows.)
- Admin permission only if you use "Block adult sites" (Windows will ask).

INSTALL (2 minutes)
1. Right-click FocusBoard.zip > Extract All.
2. Move the extracted "FocusBoard" folder somewhere permanent, e.g. your Documents folder.
   Do not leave it in Downloads or delete it later - the app runs from this folder.
3. Open the folder and double-click install.bat.
   If a blue "Windows protected your PC" box appears, click "More info" > "Run anyway".
   (This shows because the app isn't from a big-name publisher; it's safe.)
4. Focus Board opens. Set your challenge length, heading, colours and messages,
   then click "Apply to desktop".

Done. A "Focus Board" icon is now on your desktop, and everything starts
automatically each time you log in:
- the wallpaper with your day count and daily message,
- the live streak timer,
- a short "Still on track?" check-in (you can turn this off in the app).

USING IT
- Double-click the Focus Board desktop icon any time to change the design.
- "Restart streak from now" if you slip - it's fine, just begin again.
- "Block adult sites" switches this PC to Cloudflare's free family DNS filter.
  "Unblock" turns it off again (you'll be asked to type a sentence first).

UNINSTALL
Right-click uninstall.ps1 > Run with PowerShell.
Your wallpaper stays until you change it in Windows Settings.
